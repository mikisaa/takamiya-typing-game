# Gemini / Antigravity Prompt Guide (GEMINI.md)

本プロジェクトは AI Development Core 方式で一元管理されています。

作業開始時は、`.ai/antigravity-context.md` を読み込んで指定されている参照元および優先順位 (`core/source_priority.md`) に従ってください。

※ `.ai/antigravity-context.md` が存在しない場合は、AI Development Core の Context Builder (`scripts/prompt/build-agent-context.ps1`) で Context を再生成してから作業を開始してください。
