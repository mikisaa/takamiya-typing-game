# 08_acceptance_criteria.md — 受入基準書

本ドキュメントは、アプリケーションが満たすべき受入基準（Acceptance Criteria）を定義します。
v1.1.0 現在、全項目が検証完了し `[PASSED]` です。

---

## 1. 機能要件受入基準 (Functional Acceptance Criteria)

- [AC-001] [PASSED] 2D横スクロールゲームプレイと2種タイマーの基本動作 ([FR-001])
  - ゲーム開始後、画面左端からフォークリフトがトラックに向かって問題ごとの動的制限時間（Per-Question Forklift Timer）で等速走行し、全体ゲーム残り時間（Global Game Timer: 90秒）がカウントダウンされること。

- [AC-002] [PASSED] タイピング入力捕捉とローマ字揺れ・英数混在語の判定 ([FR-002])
  - 入力フォームへのフォーカス操作なしにキー入力が直接捕捉され、問題の日本語文・ローマ字ターゲットに対して正しく判定が行われること。
  - 「し (shi/si)」「ち (chi/ti)」「つ (tsu/tu)」「じゅ (ju/zyu/jyu)」等の複数ローマ字入力パターンがいずれも正しく受理されること。
  - `AI`, `TQM`, `2S`, `4M3H`, `OPE-MANE` 等の英数混在語のASCII部分が大文字小文字不問（case-insensitive）で入力受理され、ミスタイプ時に赤色フィードバックが表示されること。

- [AC-003] [PASSED] 積込成功演出の実行と次問題移行 ([FR-003])
  - Per-Question Forklift Timer 満了前に単語入力が完了した場合、フォークリフトが停止し、爪上の資材が荷台へ移動するアニメーションが実行され、「SUCCESS」表示とスコア・コンボ加算が行われた後、テンポを損なわず450ms以内に次の問題へ移行すること。

- [AC-004] [PASSED] タイムオーバー・失敗演出とGlobal Timerペナルティ減算 ([FR-004])
  - 入力完了前にトラックへ到達（Per-Question Forklift Timer 満了）した場合、トラック接触時の振動と資材落下のアニメーションが実行され、「MISS」表示とともにコンボがリセットされ、Global Game Timer から難易度別ペナルティ（初級-3s/中級-4s/上級-5s）が減算されて次の問題へ移行すること。

- [AC-005] [PASSED] 難易度別の車両テーマと走行速度設定の切り替え ([FR-005])
  - 初級（軽トラック）、中級（4tユニック）、上級（15tユニック）の難易度選択に応じて、積込先トラックのPixel Artグラフィックおよびフォークリフト走行時間の難易度パラメータ（KPS / 余裕秒数）が正しく切り替わること。

- [AC-006] [PASSED] 練習モードと本番モードの動作分離 ([FR-006])
  - 練習モードではスコア送信が行われず、Per-Question Forklift Timer が本番の1.5倍の余裕時間で動作し、入力結果と正確率の確認が行えること。
  - 本番モードではGlobal Game Timer（90秒）、スコア・コンボ計算、リザルト画面表示、スプレッドシートへのランキング登録が正しく実行されること。

- [AC-007] [PASSED] 7種類の仮設足場資材のランダム出現 ([FR-007])
  - 支柱、手摺、建枠、布板、筋交、ジャッキベース、小物資材パレットの7種類の資材アセットがフォークリフトの爪の上に視認可能なPixel Artとしてランダムに出現すること。

- [AC-008] [PASSED] 正解数に応じた7段階の背景建設発展 ([FR-008])
  - 正解数の累積に応じて、更地 ➔ コンテナ ➔ 家 ➔ ビル ➔ 高層ビル ➔ 東京タワー ➔ スカイツリーへと背景都市が段階的に成長・組み上がっていくこと。

- [AC-009] [PASSED] スカイツリー完成後のEXTRAステージ動的演出 ([FR-009])
  - スカイツリー完成後（33問正解後）にEXTRAモードへ移行し、都市背景に旅客機、ヘリコプター、風船、スカイダイビング、虹の動的演出が同時3個以下の範囲でランダムに発生し、ゲームプレイが継続できること。

- [AC-010] [PASSED] COMBO加算とTIME BONUSの付与 ([FR-010])
  - 連続正解によりCOMBO数とスコア倍率が上昇し、15 COMBOごとに+5秒のTIME BONUS（最大+30秒まで）がGlobal Game Timerに加算されること。ミスタイプ発生時は直ちにCOMBOが0にリセットされること。

- [AC-011] [PASSED] プレイ終了後のリザルト画面集計表示 ([FR-011])
  - 本番プレイ終了時に、Score、正解数、入力文字数、ミス数、正確率（Accuracy）、Max Combo、プレイ時間、難易度、PlayedAt、WPMがリザルト画面に正確に集計表示されること。

- [AC-012] [PASSED] 月間・歴代ランキングの表示と自己ベスト集約 ([FR-012])
  - ランキング画面で「今月」「歴代」および難易度（初級・中級・上級）を切り替えて閲覧でき、同一プレイヤーの自己最高スコアのみが抽出されて上位20件が表示されること。

- [AC-013] [PASSED] 自由入力プレイヤー名、ブラウザ記憶、およびクロスブラウザ解決 ([FR-013])
  - 本番モード開始時にプレイヤー名を自由入力でき、同一ブラウザでは前回入力名が `localStorage` から自動補完（常時編集可能）されること。別ブラウザから同一名（正規化一致）を入力した場合は同一PlayerIDへ紐付き、初回入力時は自動作成されること。練習モードでは名前入力を要求しないこと。

- [AC-014] [PASSED] Question Master v3 の完全ロードとデータ駆動出題 ([FR-014])
  - `data/questions/takamiya-typing-game-master-v3.csv`（全180問：初級60・中級60・上級60）が正常にロードされ、ID重複や必須項目欠落なく、選択難易度に応じた問題が正しく出題されること。

- [AC-015] [PASSED] GASバックエンドとの安全なAPI通信 ([FR-015])
  - 初期マスター取得、本番スコア登録、ランキング取得のAPI通信がGAS Web Appとの間で正常に完了し、ゲーム中の不必要な常時通信が発生しないこと。

- [AC-016] [PASSED] 動的走行時間モデル（文字数連動）の算出と難易度階層の維持 ([FR-016])
  - 問題ごとの実効入力文字数（`effectiveKeystrokes`）と難易度パラメータに基づいて `allowedTime` が動的に算出され、文字数が長い問題ほど入力可能時間が長くなり、かつ同一文字数では「初級 > 中級 > 上級」の入力可能時間関係が維持されること。

## 2. 非機能要件受入基準 (Non-Functional Acceptance Criteria)

- [AC-017] [PASSED] フロントエンド描画のスムーズさと60fps維持 ([NFR-001])
  - PCブラウザおよびGAS Web App iframe内において、`requestAnimationFrame` を利用したアニメーションがフレーム落ちなくスムーズに描画され、入力遅延なく快適にタイピング操作できること。

- [AC-018] [PASSED] GAS側入力バリデーションと数式インジェクション防止 ([NFR-002])
  - クライアントからの不正なスコア値（負の値や異常な文字数）がGAS側で拒否され、先頭に特殊文字（`=`, `+`, `-`, `@`）を含むプレイヤー名が安全にエスケープされてスプレッドシートへ記録されること。

- [AC-019] [PASSED] LockServiceによる同時書き込み競合防止 ([NFR-003])
  - 複数クライアントから同時にスコアが送信された場合でも、GASの排他制御によりデータの上書き破壊や欠落が発生せず安全に追記されること。

- [AC-020] [PASSED] デスクトップブラウザ解像度におけるレイアウト整合性 ([NFR-004])
  - 一般的なPCデスクトップブラウザ解像度において画面の重要要素がはみ出さず、適切にレイアウトが保持されること。

- [AC-021] [PASSED] 決定論的GASフロントエンドビルド適合性 ([NFR-005])
  - `npm run build:gas` により、`src/` 配下の全モジュールが単一HTMLバンドルへと完全にバンドルされ、未解決importやローカルファイル依存が存在しないこと。

## 3. Phase 12 (v1.1.0) 受入基準 (Phase 12 Acceptance Criteria)

- [AC-022] [PASSED] GAS Web App フロントエンド配信とAPI共存 ([FR-015])
  - クエリパラメータなしのWeb App Bare URL（`/exec`）でフロントエンド画面が正常表示され、既存の `op=health`, `op=getPlayers`, `op=getRankings`, POST `submitScore` のAPIコントラクトが100%維持されていること。

- [AC-023] [PASSED] TakamiyaTypingGame / TTG 全面リブランディング
  - UI、タイトル、フッター、バージョン（`1.1.0`）、バックエンドサービス名（`TAKAMIYA_TYPING_GAME_BACKEND`）、パッケージ情報から旧名称が完全撤廃され、新正式名称へ統一されていること。

- [AC-024] [PASSED] 自作ピクセルインラインSVGアイコン体系の適用 ([FR-017])
  - モード選択カード（本番トラック / 練習キーボード）、ランキング、ステージバッジ、SUCCESS/MISSフィードバック、リザルト指標に5色パレット準拠の自作インラインSVGが配置され、OS絵文字および文字代替（`[本]`、`[練]`等）がゼロであること。

- [AC-025] [PASSED] 車両ジオメトリ補正 & 難易度別MISS資材落下 ([FR-018])
  - 15tユニック車が `visualYOffset = -6` で上方に配置され、初級・中級トラック位置が変更されていないこと。MISS時の資材落下座標が難易度別に正しく計算され、車両手前の自然な位置に着地すること。

- [AC-026] [PASSED] localStorage キー移行の例外安全性 ([FR-013])
  - `ttg.lastPlayerName.v1` を正式キーとし、旧キー（`baseTypingGame.lastPlayerName.v1`）からの自動読み出し・移行・安全削除が例外安全に動作すること。

- [AC-027] [PASSED] GAS 実機環境におけるキーボード入力 & 描画パフォーマンス ([NFR-001])
  - Google Apps Script Web App 実URL上（iframe sandbox内）で、Chrome / Edge において高速連続タイピング、フォーカス制御、日本語ローマ字判定が遅延なく快適に動作すること。

- [AC-028] [PASSED] 回帰テスト & 実機疎通全件PASS
  - ローカル自動テスト全907件 PASS、および実稼働GASエンドポイント回帰テスト全70件 PASS を達成していること。
