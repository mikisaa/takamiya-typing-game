# 09_test_plan.md — テスト計画書

本ドキュメントは、受入基準（`08_acceptance_criteria.md`）の達成を検証するためのテストケース（Test Cases）およびテスト実施計画を定義します。
v1.1.0 現在、全項目が検証完了し `[PASSED]` です。

---

## 1. テストカテゴリ & アプローチ

1. **Unit / Logic Tests (UT)**: タイピング判定エンジン（ローマ字表記揺れ・ASCII混在語）、動的走行時間モデル（文字数連動算出式）、スコア計算ロジック、設定値ローダーの単体検証。
2. **Animation / Scene Tests (ST)**: フォークリフト走行（動的時間連動）、成功/失敗アニメーション、背景進化、EXTRA演出の描画とタイミング検証。
3. **Integration / API Tests (IT)**: フロントエンドとGAS Web Appエンドポイント間のマスター取得、スコア送信、ランキング取得通信および排他制御の検証。
4. **Data Validation Tests (DT)**: Question Master v3（全180問）のCSVスキーマ、難易度別件数（60/60/60）、重複排除、文字数分布の完全性検証。
5. **E2E / Browser UI Tests (E2E)**: PCブラウザ上でのタイトルからゲームプレイ、リザルト、ランキング画面への一連のユーザーフロー検証。
6. **GAS Build & Migration Tests (BT)**: `esbuild` による単一HTMLバンドル生成、未解決import/ローカル依存の排除、localStorage移行ロジックの例外安全性の検証。

---

## 2. テストケース一覧 (Test Cases)

- [TC-001] [PASSED] フォークリフト走行および2種タイマー動作の検証 ([AC-001])
  - **手順**: ゲームを開始し、出題ごとに算出された Per-Question Forklift Timer に従ってフォークリフトが等速走行し、Global Game Timer（90秒）が正常にカウントダウンすることを確認する。
  - **結果**: 2つのタイマーが独立して動作し、アニメーションが滑らかに描画されることを確認。

- [TC-002] [PASSED] キーボード直接捕捉・ローマ字揺れ・ASCII混在語判定の検証 ([AC-002])
  - **手順**: 入力欄をクリックせず直接キーボードから「しちゅう」「安全帯よし」を入力する（「し」を `si` / `shi`、「ち」を `ti` / `chi` で入力）。また `AI`, `TQM`, `2S`, `4M3H`, `OPE-MANE` 等の英数混在語を大文字および小文字で入力する。ミスタイプキーを入力する。
  - **結果**: 入力欄フォーカス不要で入力が即座に反映され、異なる表記パターンおよびASCII大文字小文字がいずれも正常に受理され、ミスタイプ時に赤色フラッシュが表示されることを確認。

- [TC-003] [PASSED] トラック到達前の入力完了とSUCCESS演出の検証 ([AC-003])
  - **手順**: Per-Question Forklift Timer 満了前（トラック到達前）に問題をタイピング完了する。
  - **結果**: フォークリフトが停止し、爪上の資材が荷台へ移動するアニメーションが再生され、「SUCCESS」表示とスコア・コンボ加算が行われ、450ms以内に次の問題がロードされることを確認。

- [TC-004] [PASSED] タイムオーバー時のMISS演出とGlobal Timerペナルティ減算の検証 ([AC-004])
  - **手順**: 問題を入力せずフォークリフトをトラックへ到達（Per-Question Timer 満了）させる。
  - **結果**: トラック接触時の車体振動と難易度別資材落下アニメーションが実行され、「MISS」表示とともにコンボが0になり、Global Game Timer から難易度別ペナルティが減算されることを確認。

- [TC-005] [PASSED] 難易度切り替えによる車両テーマと走行パラメータの検証 ([AC-005])
  - **手順**: 初級、中級、上級を切り替えてゲームを開始する。
  - **結果**: 初級=軽トラック、中級=4tユニック、上級=15tユニックのグラフィックおよび難易度別KPSパラメータ（2.0 / 3.2 / 4.5）が正しく反映されることを確認。

- [TC-006] [PASSED] 練習モードと本番モードの動作仕様の検証 ([AC-006])
  - **手順**: 練習モードと本番モードでそれぞれプレイを完了する。
  - **結果**: 練習モードではスコア送信が行われず、走行時間が本番の1.5倍の余裕時間で動作し練習結果が表示される。本番モードでは90秒Global Timer、スコア集計、リザルト画面表示、スプレッドシートへの記録が正しく行われることを確認。

- [TC-007] [PASSED] 7種類の仮設足場資材スプライトの出現検証 ([AC-007])
  - **手順**: 複数回問題を解き、爪上の資材グラフィックを確認する。
  - **結果**: 支柱、手摺、建枠、布板、筋交、ジャッキベース、小物資材パレットの全7種が正常に描画され、ランダムに出現することを確認。

- [TC-008] [PASSED] 正解数に応じた背景建設発展の段階的成長検証 ([AC-008])
  - **手順**: 0問、3問、7問、12問、18問、25問、33問と正解を重ねる。
  - **結果**: 更地 ➔ コンテナ ➔ 家 ➔ ビル ➔ 高層ビル ➔ 東京タワー ➔ スカイツリーへと背景構造物が順次建設・発展することを確認。

- [TC-009] [PASSED] EXTRAステージ移行と動的オブジェクト出現の検証 ([AC-009])
  - **手順**: 33問正解後にゲームを継続し、背景の動的演出を確認する。
  - **結果**: EXTRAモードへ移行し、都市背景に旅客機、ヘリコプター、風船、スカイダイビング、虹が表示され、同時表示数が最大3個以内に制御されることを確認。

- [TC-010] [PASSED] 連続正解によるCOMBO倍率とTIME BONUS付与の検証 ([AC-010])
  - **手順**: ノーミスで15問連続正解し、Global Game Timer とスコア倍率を確認する。途中ミスタイプを発生させる。
  - **結果**: 15 COMBO達成時にGlobal Game Timer に+5秒加算され、スコア倍率が上昇すること。ミスタイプ時にCOMBOが直ちに0へリセットされることを確認。

- [TC-011] [PASSED] 本番リザルト画面の集計値表示の検証 ([AC-011])
  - **手順**: 本番モードを終了し、リザルト画面の各表示項目を確認する。
  - **結果**: 確定計算式通りのスコアおよび各指標が正確に集計・表示されることを確認。

- [TC-012] [PASSED] 月間・歴代ランキングの表示と自己ベスト集約の検証 ([AC-012])
  - **手順**: ランキング画面を開き、「今月」「歴代」および難易度タブを切り替える。同一プレイヤーで複数回スコアを送信した状態を確認する。
  - **結果**: 各プレイヤーの最高スコアのみが抽出され、期間・難易度別に上位20件が正しくソート表示されることを確認。

- [TC-013] [PASSED] 自由入力プレイヤー名、ブラウザ記憶、およびクロスブラウザ解決の検証 ([AC-013])
  - **手順**: 本番モード設定画面で名前を入力してゲーム開始、リロード後の自動補完、別名への編集上書き、別ブラウザでの同一名入力時のスコア送信を検証する。
  - **結果**: 前回名が安全に復元され、未登録名は新規PlayerIDが生成され、既存名は同一PlayerIDが再利用されることを確認。

- [TC-014] [PASSED] Question Master v3 (全180問) のロードとデータ完全性の検証 ([AC-014])
  - **手順**: `takamiya-typing-game-master-v3.csv` をロードし、行数、カラム構造、難易度別件数（初級60/中級60/上級60）、ID重複の有無をテストする。
  - **結果**: 180問すべてが正常にロードされ、ID重複ゼロ、必須フィールド欠落ゼロで出題プールに反映されることを確認。

- [TC-015] [PASSED] GAS APIエンドポイント通信の検証 ([AC-015])
  - **手順**: 初期ロード時のGET通信、スコア送信時のPOST通信、ランキング取得時のGET通信を実行する。
  - **結果**: 適切なJSONレスポンスが返却され、ゲームプレイ中の不要な通信が発生しないことを確認。

- [TC-016] [PASSED] 動的走行時間モデル（文字数連動）と難易度階層の検証 ([AC-016])
  - **手順**: 初級、中級、上級において算出される `allowedTime` をテストする。同一文字数における3難易度の時間を比較する。
  - **結果**: 文字数が長いほど走行時間が合理的に延長され、min/max clamp が正常に機能し、同一文字数において「初級 > 中級 > 上級」の時間が厳格に維持されることを確認。

- [TC-017] [PASSED] 60fpsゲームループのフレームレート安定性検証 ([AC-017])
  - **手順**: ブラウザの開発者ツールでFPSパフォーマンスをプロファイリングする。
  - **結果**: 60fps前後で安定して描画され、タイピング時の入力遅延や画面のカクつきが発生しないことを確認。

- [TC-018] [PASSED] GAS入力検証およびFormula Injection防止の検証 ([AC-018])
  - **手順**: プレイヤー名に `=1+1`, `@SUM(A1:A5)` 等の特殊文字を指定したスコア登録ペイロードをGASへ送信する。
  - **結果**: 先頭に `'` が付与されて安全にスプレッドシートへ文字列として格納され、数式として実行されないことを確認。

- [TC-019] [PASSED] LockServiceによる同時書き込み競合制御の検証 ([AC-019])
  - **手順**: 複数クライアントから同時にスコア送信を実行する。
  - **結果**: LockServiceにより直列化され、すべてのレコードが欠落なくScoresシートへ追記されることを確認。

- [TC-020] [PASSED] デスクトップ解像度レスポンシブ表示の検証 ([AC-020])

  - **結果**: 単一バンドルに全ロジック・スタイルが内包され、未解決importやローカルファイル参照がゼロであることを自動テスト（`testGasBuild.js`）で確認。

  - **結果**: 旧名称の残存ゼロ、正式名称 `TakamiyaTypingGame` / `TAKAMIYA TYPING GAME` / `TTG` への完全移行を自動テスト（`testRebrandAndSvg.js`）で確認。

  - **結果**: OS絵文字ゼロ、5色パレット準拠のピクセルインラインSVGが正常に出力されることを確認。
